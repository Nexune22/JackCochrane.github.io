3D Unity FPS Game

Dr Blue's Evil Plan is a 3D first-person shooter game I developed using the Unity game engine and C# scripting. This was my first attempt at creating a 3D game, and as such it features simplistic graphics, basic game mechanics and loose narrative elements through 4 Levels of "clear the area" style missions.

What I Learned

Unity Development

Coming into this project, I had little experience with the Unity game engine. Through the development process, I learned how to use Unity's interface, manage game objects, and implement basic gameplay mechanics to create a simple functional game

C# Programming

Until the point of creation for this project, I had no experience with C#, or any kind of object-oriented programming. This project allowed me to develop my understanding of the language including its syntax, features, and how it intergrated with the Unity engine.
